# ADR 0004: Pin the Job Finder search and saved-job TypeScript contract

- Status: Accepted
- Date: 2026-07-27
- Decision owner: Job Seeker Copilot

## Context

SEARCH-12 and DOCGEN-16 need a typed browser boundary for Job Search and the
owner-scoped saved-job resource. The retained client source imports
`src/app/api/job-finder`, but that ignored directory is absent in a clean clone
and had no reviewed input in the contract lock.

Job Finder Gateway 1.2.0 now owns authenticated search plus save, list, retrieve
and unsave operations. Save returns a server-owned `savedJobId`, immutable
snapshot identity/version/digest fields and explicit create/replay outcomes.
Document Generation must use that ID instead of browser-supplied job content.

## Decision

Pin the exact Job Finder Gateway 1.2.0 OpenAPI document from producer merge
`3effd28429fe10eb56921beb9098b97ffcb3a7b5` in the client contract lock.
Generate its Angular client with OpenAPI Generator 7.23.0 into the canonical
ignored path already imported by the retained Job Search code:
`src/app/api/job-finder`.

Contract policy requires search and all four saved-job operations, HTTP Bearer
security without `X-User-Id`, stable UUID identity, immutable snapshot
version/digest/source-state fields and `CREATED`/replay save outcomes. Policy
tests rewrite reviewed fixtures with matching checksums to prove unsafe drift
still fails closed. Deterministic generation compares every generated byte and
compiles both the Job Finder and Document Generation consumers.

## Consequences

The clean client can reproduce the reviewed Job Finder boundary without a
sibling repository or committed generated output. ADR 0005 subsequently
activated only the server-side search and saved-job routes through the HttpOnly
session BFF. Every retained Job Finder application route and the complete
`/api/v1/document-generation` prefix remains fail-closed.

This does not claim SEARCH-12, GW-02 or DOCGEN-16 complete. The Angular journey
must still save the selected result, start/recover the durable operation,
preview drafts and require explicit approval.
